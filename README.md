# Marketing-Campaign-Analysis
Marketing campaign data analysis dashboard built in Tableau using synthetic data. Focuses on channel performance, trend insights, and campaign-level metrics for learning and showcasing data visualization skills.

## 🔗[Link to Tableau Dashboard](https://public.tableau.com/shared/M5C84Y9QB?:display_count=n&:origin=viz_share_link)
<img width="1465" height="1017" alt="Dashboard_Screenshot" src="https://github.com/eboniethomas16/Marketing-Campaign-Analysis/blob/main/Campaign%20Analysis%20Overview%20Tableau%20screenshot.png" />

### 📊 What This Dashboard Shows
The dashboard includes:

Channel-level comparisons to evaluate how selected channels perform against all others.

Time‑series trends for key metrics such as spend, revenue, clicks, conversions, impressions, and leads.

Campaign-level breakdowns with bar charts showing performance across multiple display, paid social, and other marketing campaigns.

Interactive filters that allow users to explore specific channels and metrics (CPC, CPL, ROAS, etc.).

This structure mirrors how marketing teams assess performance, optimise spend, and identify opportunities for improvement.
## 🗂️ Dataset
This dashboard is built using a publicly available synthetic dataset designed for analytics learning and portfolio development:

### Analytics Engineering. (2026). Marketing Campaigns & Conversions Dataset (Version 1.0.0) [Data set].  
https://www.analyticsengineering.com/datasets/marketing-campaigns

The dataset includes campaign‑level metrics across multiple digital channels, making it ideal for exploring marketing KPIs and building interactive visualisations.
